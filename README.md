# 🧮 Calculadora de Média Escolar em Python

Este projeto foi desenvolvido como atividade prática para exercitar lógica de programação em Python e boas práticas de documentação utilizando Markdown no GitHub.

## 📋 Sobre o Projeto
O script solicita duas notas ao usuário, calcula a média aritmética e exibe o status final do aluno (Aprovado, Recuperação ou Reprovado), contando também com tratamento básico de erros caso o usuário digite texto em vez de números.

## 🚀 Tecnologias Utilizadas
* **Python 3** (Linguagem principal)
* **Git / GitHub** (Versionamento e hospedagem)

## ⚙️ Como Executar o Código

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório ou baixe o arquivo `script.py`.
3. Abra o terminal na pasta onde o arquivo está localizado.
4. Execute o seguinte comando:

```bash
python script.py
```

*(Nota: Em alguns sistemas Linux ou macOS, pode ser necessário usar `python3 script.py`)*
